# JPMorgan Chase First POC

## Objective
Demonstrate that external account events can be filtered, interpreted through a Red Hat lens, ranked, and delivered as concise seller-ready actions.

## Open these first
1. `First_PoC_TLDR_and_Design.docx`
2. `JPMC_Account_Pulse_First_PoC.xlsx`
3. `visuals/First_PoC_Flow_Visual.png`

## What this POC proves
- A high-volume external information set can be filtered into a small set of seller-relevant signals.
- Signals can be linked to defined Red Hat motions without claiming a customer opportunity.
- A seller can see what changed, why it matters, and what to validate next without reading raw news.

## What it does not yet prove
- Automated data collection
- Authorized Red Hat internal-data integration
- Gmail delivery
- CRM integration
- RAG-based Red Hat knowledge retrieval
- Enterprise-scale operation
